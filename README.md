# Actividad 1.1: Compilando y ejecutando aplicaciones de consola

## 1. Presentación
En esta actividad 1.1: Compilando y ejecutando aplicaciones de consola, puse en práctica lo que se vio anteriormente en la asignatura de Fundamentos de Programación.

Contiene las siguientes secciones:
* Variables y tipos de datos básicos.
* Condicionales y bucles (control de flujo).
* Funciones y parámetros.

Estas secciones me ayudaron a practicar con la plantilla de Google Colab. En "Variables y tipos de datos básicos" actualicé con mis datos, 
también quise agregar adicional mi fecha de nacimiento. En la segunda sección, se agregaron 10 nuevas edades; con esto se logra conocer cómo se ejecutan los bucles.
En "Funciones y parámetros" se modificó el IVA al 8%, y se agregaron 10 nuevos productos con precios decimales. Investigué más acerca de esto de definir una función, en este caso fue el IVA.

## 2. Instrucciones de Ejecución
Para ejecutar este proyecto, sigue estos pasos:
1. Abre el archivo de Google Colab (`.ipynb`) adjunto en este repositorio.
2. Asegúrate de conectar el entorno de ejecución en Google Colab.
3. Ejecuta cada celda de código en orden (de arriba hacia abajo) para ver los resultados en la consola.
